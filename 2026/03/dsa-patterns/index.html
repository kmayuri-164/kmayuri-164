🧩 PART 1 — ALL DSA PATTERNS (Categorized by Difficulty)

🟢 EASY LEVEL PATTERNS (Foundation)

These are MUST MASTER FIRST.

1. Arrays Basics

  • Traversal
  • Min/Max
  • Frequency

Study Plan

  1. Learn array basics
  2. Practice loops + conditions
  3. Understand brute force

Practice Plan

  • Solve 15–20 easy problems
  • Focus: correctness > speed

2. Hashing (Map/Set)

  • Counting frequency
  • Lookup optimization

Study Plan

  1. Learn hashmap operations
  2. Understand O(1) lookup

Practice

  • Two Sum
  • First unique character
  • Frequency problems

3. Two Pointers

👉 Used for sorted arrays, pairs, palindrome (LeetCode )

Study

  1. Left-right pointer
  2. Slow-fast pointer basics

Practice

  • 20 problems (easy → medium)

4. Sliding Window

👉 Converts O(n²) → O(n) (LeetCode )

Study

  1. Fixed window
  2. Variable window

Practice

  • Substring problems
  • Max/min window

5. Prefix Sum

  • Precompute sums

Study

  1. Build prefix array
  2. Query in O(1)

Practice

  • Range sum
  • Subarray sum

6. Basic Recursion

  • Function calls itself

Practice

  • Factorial
  • Fibonacci
  • Simple DFS intro
